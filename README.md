# Deck Bar Website 🌴

Site completo para o **Deck Bar** – Ilha da Gigóia, Rio de Janeiro.

## Estrutura de Arquivos

```
DeckBar/
├── index.html        → Página inicial (hero, sobre, destaques, galeria, contato)
├── cardapio.html     → Cardápio completo (entradas, frutos do mar, peixes, drinks)
├── galeria.html      → Galeria de fotos com filtros e lightbox
├── style.css         → Estilos globais compartilhados
└── images/           → Todas as imagens (já estão na sua pasta)
    ├── logo.jpg
    ├── frente_restaurante.png
    ├── deck1.jpg → deck9.jpg
```

## Como Usar

1. Certifique-se de que as imagens estão em `/images/` dentro da pasta do site
2. Abra `index.html` no navegador — funciona sem servidor
3. Para publicar: basta subir a pasta no seu host/repositório

## Tecnologias

- HTML5 + CSS3 (sem frameworks)
- Vanilla JavaScript
- Google Fonts (Playfair Display + Cormorant Garamond + Josefin Sans)
- Phosphor Icons (via CDN)
- Totalmente responsivo (mobile/tablet/desktop)
